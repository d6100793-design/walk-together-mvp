# 같이걷기 MVP — 동행자별 경로

같은 출발·도착이라도 **누구와 걷느냐에 따라 다른 길**을 추천하는 프로토타입.

👉 **https://d6100793-design.github.io/walk-together-mvp/** (모바일에서 열어보세요)

## 보는 법
1. 지도를 두 번 눌러 출발지·도착지를 정하거나, 위 예시 버튼을 누르세요
2. 동행자 칩(연인/부모님/혼자/반려동물)을 바꾸면 경로가 달라집니다
3. **"⇄ 네 동행자의 선택 한번에 보기"** — 네 명이 고른 길이 동시에 깔립니다
4. **"🔁 목적지 없이 산책"** — 시간만 넣으면 돌아오는 순환 코스 5개

## 구조
- **1단계** Valhalla pedestrian costing을 7가지로 달리 줘 후보 경로 생성 → 중복 제거
- **2단계** 각 후보의 계단·오르막·도로등급·횡단보도를 OSM에서 실측 → 동행자 가중치로 재랭킹

2단계가 따로 필요한 이유: 횡단보도 회피는 Valhalla costing에 옵션이 없어서,
부모님 설정으로 요청해도 횡단보도 12개짜리가 나옵니다.

## 알아둘 것
- 검색에 **10~20초** 걸립니다. 공개 데모 서버(FOSSGIS)라 동시 요청 4개가 한계입니다.
- 데이터: OpenStreetMap · CARTO · Valhalla(FOSSGIS) · Nominatim
